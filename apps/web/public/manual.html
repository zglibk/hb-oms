第0章 快速上手

0.1 系统功能设计

随时回答「订单做完了多少、仓库还有多少、还欠客户多少」

系统围绕每张订单呈现四个数字：

数字含义
订单数客户订购数量，统一折算成「支」
完成数累计成品入库数量
库存数当前成品结存数量
欠数两个口径并列：成品欠数（还差多少没做完）与发货欠数（还欠客户多少货）

业务主线（也是本手册的章节顺序）：

录订单→ 部件外发（可选）→ 外发回货（可选）→ 装配→ 成品入库→ 成品出库
本系统不做什么：不排产、不做多级审核、不做车间报工、不管拉槽/冲压工序。这些环节仍按现行方式在车间进行，系统只记录订单跟踪需要的结果。

0.4 通用操作约定

  • 数量单位：系统内所有数量以「支」为准。订单单位可选「套」或「支」，1 套 = 2 支（滑轨两支一组），系统自动折算。
  • 规格：可按 mm 或英寸录入，换算默认 1 英寸 = 25mm（我司口径，不是国标 25.4）；系统里统一存 mm。这个系数可由管理员在「系统配置 → 业务字段 → 单位换算」调整，见第9章。
  • 卡口产品分左右：产品类型组合里只要含「卡口」，部件、装配、库存、出入库全部按左/右分开算，左右不串量。
  • 带 * 的是必填，没填完保存会红框提示。
  • 已确认的单据不能改：成品出入库单一旦确认，只能开红字冲销单更正，不能直接编辑或删除（见 4.3）。
  • 列表页顶部都有筛选条，改完点「查询」；分页在列表底部。

第1章 第一步：录入客户订单

菜单位置：生产管理 → 订单管理 → 新增订单

1.1 填写顺序：四级结构

一张订单分四层，从上往下填：

订单→ 产品行→ 部件组→ 部件行（自动展开）
  1. 订单信息：选客户（选中后自动带出默认业务员、跟单员、交货地址），填 PO#、生产单号、订单日期。
  2. 产品明细：一张订单可以有多个产品，点「添加产品」增加。每个产品填货号、产品类型、规格、数量、表面处理、交期等。
  3. 部件组：每个产品下至少一个组。系统按轨道节数自动铺好——三节轨给「外轨/中轨/内轨」三个组，二节轨给「外轨/内轨」两个组（见 1.3）。
  4. 部件行：不用手填，系统按组类型 + 轨道节数 + 是否卡口自动展开（如整品组 = 外轨/中轨/内轨各一行，外轨组 = 外轨一行）。只有追溯码和备注可以微调。
  5. 需要图文说明的（包装要求、客户来函截图等）写在产品明细上方的「订单备注」编辑区里。
  6. 点右上角「保存」。

1.3 部件组怎么拆

部件组管的是「零件出厂前的那一段」：外发去电镀是按部件分开送、分批回厂的，所以外发登记锚定在部件组上；生产图号、版本、料厚也都填在部件组里。

系统已经按轨道节数帮你铺好了：新增产品行时，三节轨自动生成「外轨 / 中轨 / 内轨」三个组，二节轨生成「外轨 / 内轨」两个组，不用手动加。
这样每个部件的外发回厂都能单独跟踪——哪个部件回厂了、回了多少，台账展开一看就知道。
装配、入库、出库、台账不按部件组走，按「产品」走。车间装出来的是整套滑轨，入库、发货的也是整套，不会把外轨、中轨、内轨拆开分别入库。 所以这几个环节的每一行都是一个产品；部件组退到台账的展开行里，看图号、料厚和外发回厂进度。
  • 改了轨道节数，部件组会自动跟着调整：三节轨改成二节轨时，中轨组会被移除（二节轨本来就没有中轨）；改回三节轨会把中轨组补回来。如果中轨组已经填了内容，系统会先问你一句。
  • 拆组不拆数量：各组的支数默认都等于产品支数，不是把总数分摊到各组。10 套产品拆三个组，三个组都是 20 支。
  • 不想分那么细：把多余的组删掉，组类型改成「整品」，就回到按整套滑轨记账的老做法。「外中轨」也还在，缓冲类习惯按「外中轨 + 内轨」两组走的照旧。
  • 老订单不受影响：以前录的整品组订单，打开编辑还是原样，不会被改成三个组。
别让「整品」和部件组同时存在。「整品」本身就包含外轨、中轨、内轨，再加一个「内轨」组，内轨就被算了两遍。要拆就拆干净，不要留整品组。
要外发的产品，系统会自动把「外中轨 / 整品」拆成单个部件的组。只要表面处理不是「无」，选了「外中轨」或「整品」就会立刻拆开并弹提示—— 因为零件是分开送去电镀、分批回厂的：挂一个「外中轨」组的话，回厂只能记成一条，分不出外轨、中轨各回了多少；单重也是按部件建档的，混在一起算重量会偏。
拆开时生产图号 / 版本 / 料厚会原样复制到每一行，你核对后改掉不一样的那几项就行，不用重新录。这条和分不分体无关，普通整品订单同样适用。
省事技巧——「按第一行填充」：同一产品的几个组往往只有组类型不同，图号、支数都一样。 先把第一行（外轨）填好，再点部件组表格上方的「按第一行填充」，图号 / 版本 / 料厚 / 支数 / 备注就一次性灌到后面所有组，组类型不变。
版本号是按部件各取各的——填充时会照图号重新带一遍开单信息，外轨组取外轨版本、内轨组取内轨版本，不会把外轨的版本安到内轨上。
料厚是照第一行填的，三个部件料厚不一样的（如 1.2 / 1.0 / 1.2）填完再改那两行就行。后面的组已经填过内容时，会先弹窗问一句再覆盖。

分体出货：客户把一支滑轨拆开下单

有的客户会把一支三节轨拆成两行下单：一行只要「外中轨」（外轨+中轨组装后打包）、一行只要「内轨」， 分开包装、分开出货，不组装成整品。这种订单照客户的单子录成两行产品，每行打开「分体出货」开关：

  • 只有三节轨能开：二节轨只有外轨和内轨两个部件，业务上不拆单下单，所以二节轨的开关是灰的。把已开分体的产品行改成二节轨，开关会自动关掉并提示。
  • 开关打开后，部件组留哪几组，这一行就出什么货：外中轨那行删掉「内轨」组、只留「外轨 / 中轨」；内轨那行只留「内轨」组。开关旁会实时预览出货形态（如「出货形态：外中轨」）。
  • 型号会自动带上形态后缀：装配、出入库、台账里这两行分别显示「45#缓冲外中轨」「45#缓冲内轨」，不会混成同一个「45#缓冲滑轨」。
  • 每一行都照常走装配：外中轨那行要把外轨+中轨组装，只出单个部件的行（如内轨）也要装配自身的小零件——都在装配管理录批次，入库前都受可入库量约束，和普通产品一样。
  • 四个数按行各自算：外中轨和内轨各有各的订单数、入库、出库和欠数，出货进度互不影响。
开着「分体出货」但部件组把外/中/内凑齐了，那就是整品——保存会被拒绝，请删掉不出货的组，或者关掉开关。

1.4 订单列表常用操作

展开列表行前面的箭头，可以看到该订单下每个产品的部件组明细（客户图号、型号、规格、图号、料厚、交期）。

复制历史订单建新单

客户经常下相同或相近的订单。这时不用从头录：在订单列表找到那张历史订单，点操作列的「复制」，表单会把它的产品行、部件组、图号料厚、备注（含图文订单备注）全部预填好，你只改不一样的地方（通常就是规格、数量、交期），保存即成一张全新的订单（系统单号重新生成）。

  • 这些内容不会带过来，要重新填：PO#（新订单文件必然是新号）、交期（防止沿用旧交期忘了改）、订单附件（旧单的客户文件不该挂到新单上）；订单日期自动重置为今天。
  • 生产单号会预填一个「后缀递推」的建议值：原单是 GLI46212-A 就建议 GLI46212-B，原单没有字母后缀就建议补 -B——这只是照顾「同 PO 追加」的惯例，可以随意改掉或清空，以实际生产单号为准。
  • 客户昨天下了单、今天又下一张只有数量或规格不同的：复制昨天的单，改掉数量（和规格），填上今天的 PO# 保存——不要去改昨天那张订单，两张客户订单文件就该是两张系统订单，台账才对得上客户的对账单。
客户新发来的订单连 PO# 都和之前一样怎么办？分两种情况：
① 原订单还没走外发/装配/出入库——这其实是客户对同一张 PO 的变更，直接编辑原订单改数量、加产品行即可；
② 原订单已经走了下游流程（系统禁改）——把增量部分复制成新单，PO# 照填同一个（系统允许重复），生产单号加后缀区分（如 GLI46212-A / GLI46212-B），备注写明「同 PO 追加」。对账时按 PO# 搜索，两张单加总就是客户这张 PO 的总量。
新建保存时如果系统里已有同 PO# 的订单，会弹一个提醒让你确认——同 PO 追加属正常操作，点「继续保存」即可；提醒防的是把同一份订单文件重复录两遍。

导出总计划

订单列表工具栏的「导出总计划」按钮，把当前筛选条件下的订单导成 Excel，一行 = 一个产品，带客户、订单编号、货号、规格、数量、图号料厚，以及成品入库 / 成品欠数 / 成品出货 / 发货欠数 / 库存数这几个进度数。

  • 导的是当前筛选的全部订单，不是当前这一页——点之前会先弹出条数让你确认。
  • 一个产品拆了多个部件组时，部件组 / 图号 / 版本 / 料厚会按组序并列显示（如 外轨/中轨/内轨、DWG-OM/DWG-IN），进度数是这个产品的合计。
  • 和台账导出（第 5 章）都是一行一个产品，区别在字段：总计划多了 PO#、产品名称、材质、是否新单、出口国家、订单状态，给业务和 PMC 看；台账那张列序对齐车间的手工跟踪表。
  • 单次上限 5000 行，超了会提示你先缩小筛选范围——不会悄悄截断。

导出单据（生产任务单）

订单列表操作列的「导出单据」按钮，打开这张订单的《生产任务单》——版式对照车间现行的纸质任务单，用来下发生产。

  • 上半部分是订单信息表：生产订单号、客户采购单编号（PO#）、订单日期与交期，逐产品行列出 货号 / 部件编码 / 客户图号 / 产品要求描述 / 尺寸 / 颜色 / 数量 / 图号 / 分类，末行合计。「分体出货」的订单一行一个部件形态（外中轨 / 内轨），共同的要求、尺寸、图号会像纸质单一样合并显示。「客户图号」列受第9章的业务字段开关控制——管理员停用后，任务单上这一列会整列消失。
  • 下半部分就是订单表单里「订单备注」富文本的内容——文字、图片、表格原样呈现。想让任务单带包装要求、物料信息卡这类内容，就录在订单的富文本备注里。
  • 页面右上角「打印」走浏览器打印；「导出PDF」点一下直接下载 PDF 文件（不弹打印对话框），文件名自动是「生产任务单-订单号」。PDF 由服务器生成，版式与屏幕上看到的完全一致，生成需要两三秒，按钮转圈时请稍候。
  • 底部签名栏「制单」自动填订单的跟单员、「业务审核」自动填业务员（都取订单上填的人，不是录单账号），生产部 / 技术部审核留白手签。已作废的订单不能再导出——作废单不该再下发生产。

第2章 第二步：外发件回厂（可选）

菜单位置：生产管理 → 外发管理。

系统只记「回厂」这一件事。东西发出去的时候不用过磅、不用在系统里建单—— 货回厂了，登记一条记录就行：谁做的、什么时候回的、回了多少。

2.1 什么时候要外发

产品需要做表面处理（电镀、电泳、喷涂、封漆、平滑漆…）时，把半成品部件发给外协加工厂处理，处理完再收回来。

  • 产品的表面处理选「无」（镀锌板等），就不需要这一步。
  • 发出去的加工单还是照原来那样手写，系统不打印。

2.2 登记回厂

先选「录入方式」，这决定了你要填哪一列：
  • 按数量（默认）——加工商送货单上只印了数量时用。直接填数量就能保存， 重量和单重是选填的，填了也不会反过来改你的数量。
  • 按重量折算——货过了磅时用。填重量与单重，数量自动算出（重量 ÷ 单重，四舍五入），算完还能微调。
每次进入登记页都默认「按数量」（不记忆上次的选择，避免不知不觉停在折算模式里），要折算再手动切。切换方式不会清空已经填好的内容。
  1. 点「登记回厂」，先在「公共信息」里选录入方式（决定下面该填哪一列），再选加工商（下拉来自「基础数据 → 供应商」，没维护到的新厂也可直接输入）与回厂日期——后两项各行共用。
  2. 再到「回厂明细」点「添加部件组」（没有明细时页面中间也会有这个按钮），选择器只列出需要表面处理的部件组，可以搜订单号/客户/生产单号/型号/图号，一次可多选。
  3. 按数量：逐行照送货单填回厂数量即可。
    按重量折算：逐行填回厂重量（磅秤实测，kg），单重会按这一组对应的部件从部件信息自动带出（外轨组带外轨的、内轨组带内轨的），带出的不对或没带出直接改，数量随即算好。
  4. 表面处理和颜色按订单自动带出，实际做的不一样可以改（颜色字段被管理员全局停用时不显示，见第9章「业务字段开关」）。
  5. 点「保存」。同一天从同一家回来的几种货，这样一次就录完了。
数量为准，重量只是佐证。入库、入账、台账的「外发已回货」看的都是回厂数量； 重量与单重是给对账用的，缺了不影响记账——所以送货单上没有重量，照样可以正常登记。
如果三个数都填了、但数量与「重量÷单重」相差超过 10%，保存时会提示你核一眼（只提醒，确认后仍按你填的数量入账）。
为什么不自动填订单数量：订单数是「应该做多少」，这里要记的是「实际回来多少」。拿订单数当默认值，很容易顺手存下一个没核对过的假数。

每行会自动带上订单侧信息供核对：生产单号、产品型号、规格、订单数量与单位、生产图号、材料厚度。这些是订单录入时定的，这里只读不改。

2.3 改错与删除

操作能改什么
编辑加工商、回厂日期、表面处理、颜色（停用时不显示）、重量/单重/数量、备注。部件组不能改——换组等于换了一条记录，请删掉重录
删除整条删掉。台账的「外发已回货」会同步减少，谁删的系统有记录
  • 同一个部件组可以录多条：分几批回来就登几次，台账按合计算。
  • 列表可以按加工商、表面处理、回厂日期区间筛选；单号列旁的 ⓘ 图标能看到谁录的、什么时候录的。

第3章 第三步：装配

菜单位置：生产管理 → 装配管理

3.1 装配批次是什么

装配是唯一纳入系统的生产工序，但只做轻量跟踪：计划员按产品录几条「批次」记录，写清楚打算什么时候装、装多少、实际什么时候装完的。不做工序报工、不记机台工时。

  • 装配管理列表按订单产品一行——装出来的是整套滑轨，一条产线不会按外轨/中轨/内轨分别排产。显示批次数、已录量、已完成量、最早未完成的计划日、是否逾期。
  • 点「录装配」按钮进入装配批次页面，在里面看该产品已有的批次并录新批次；页面下方还有一块「装配完成历史」——按实际完成日期从新到旧列出已完成的批次，带数量、车间、登记人和登记时间，谁哪天登记完成了多少支一眼可查。点「返回列表」回装配管理。
  • 一个产品可以分多批装配，比如先装 500 支入库交货，剩下的下周再装。
  • 卡口产品要选边别（左/右），左右分开算；非卡口产品不用选。

3.3 可入库量：入库闸门

成品入库必须先有装配。系统按下面这个式子卡：

可入库量 = Σ 已完成装配量 − Σ 已入库量（按产品算；卡口产品左右分别算）

装配批次页面上方会直接显示每个边别的「已录 / 已完成 / 已入库 / 可入库」四个数，一眼就知道还能入多少。成品入库单选行时也会显示该产品的可入库量。

  • 支持部分装配部分入库：装完 500 支就能先入库 500 支，不用等全部装完。
  • 期初录入的入库不受这个闸门约束（上线前的存量本来就没有装配过程，见 7.2）。这是唯一的例外——「分体出货」的行（含只出内轨的行）同样要先录装配再入库。
  • 删批次、下调数量、把已完成退回计划中，这三种操作系统都会复核可入库量，会导致为负就整笔拒绝，提示先去红字冲销对应的入库单。
  • 卡口产品左右不串量：左边装了 4 支、右边装了 3 支，右边最多只能入 3 支，不能借左边的额度。

超装配（装的比订单数还多）是允许的，只给黄色提示。

3.4 导出装配记录

装配管理页工具栏的「导出到Excel」按钮，把当前筛选条件下的装配情况导成 Excel，文件里有两张表：

  • 装配汇总：一行一个产品，与页面上看到的一致——订单编号、客户、货号、型号、规格、车间、订单数 / 已排产 / 已完成 / 未装配、批次数、装配进度、待完成计划日、最近完成日、交期、是否逾期。
  • 装配批次明细：上面那些产品的逐批记录，按完成日期从新到旧——边别、车间、计划开始 / 计划完成 / 实际完成、装配数量、状态，还有登记人和登记时间。想查「哪天谁登记装完了多少支」看这张。
  • 导的是当前筛选的全部记录，不是当前这一页——点之前会先弹出条数让你确认。想导全部就先把筛选条件清空。
  • 单次上限 5000 行（按汇总表的行数算），超了会提示先缩小筛选范围；筛选结果为空时会直接提示，不会给一张只有表头的空表。
  • 车间等字段导出的是中文，可以直接打印出来贴工位或对手工账。

第4章 第四步：成品入库与出库

菜单位置：物料管理 → 成品出入库

4.1 成品入库

  1. 点「新增」，业务类型选生产入库，填单据日期；车间选填（装一~装九下拉，供追溯）。
  2. 点「添加产品」选要入库的订单产品——入库的是装配好的整套滑轨，不按外轨/中轨/内轨分开入。选择器会显示每个产品的可入库量，心里有数。「分体出货」的行按行入（型号带外中轨/内轨后缀），同样看可入库量。
  3. 填入库数量（卡口产品按左右分行）。
  4. 保存 → 单据是草稿状态，此时还能改、能作废。
  5. 核对无误点「确认」。确认这一步才真正增加库存、并检查装配闸门。
确认时如果提示「超过可入库量」，说明装配那边还没录够。回到装配管理，把已经装完的批次填上「实际完成」日期。

急单：一批装完可以分多次入库，边入边发

闸门卡的是数量不是「装完才准入」——公式是 可入库量 = Σ已完成装配 − Σ已入库，每次确认只校验「本次入库量 ≤ 可入库量」。 所以一个装配批次可以分好几张入库单陆续入，入一批就能发一批，不用等整批入完。

比如装配录了一条 500 支的完成批次：

动作结果
入库 200库存 +200，可入库量剩 300 → 这 200 支立刻可以出库发走
再入库 250可入库量剩 50
再入库 50可入库量归零
还想再入被拒——已装配的 500 支已经全部入完
装配再录 300 支完成可入库量恢复 300，又能继续入库
急单赶货的标准打法：车间装完一部分，装配管理就把这部分录成一条已填实际完成的批次， 仓库随即入库、出库发走；剩下的装完再录一条批次接着入。全程不需要等整个订单装完。

外发同理：同一个部件组可以分批回厂、登多条记录（比如先回 300 支， 过两天再回 400 支），互不影响，台账按合计算。见 2.2。

4.2 销售出库

同样的操作，业务类型选销售出库。确认时会检查库存，不够扣会直接拒绝。

出库确认后，台账的「发货欠数」立刻减少；如果这张订单所有产品的发货欠数都清零了，订单会自动完结（见 5.4）。

4.3 单据做错了：红字冲销

已确认的单据不能编辑、不能删除、不能作废。这是财务口径的要求——单据一旦生效就得留痕，改数字等于篡改历史。做错了走「红字冲销」。
  1. 在列表找到那张已确认的单，点「红字冲销」。
  2. 可以整单冲销，也可以按行部分冲销（比如只有一行数量填错了）。
  3. 系统生成一张红字单（单号 FGR 开头），方向与原单相反，建好立即生效。
  4. 原单原样保留，红字单上能追溯到被冲的是哪张单哪一行。
  5. 冲销完再重新开一张正确的单。

草稿状态的单据不用这么麻烦，直接编辑或作废即可。

4.4 成品库存

菜单位置：物料管理 → 成品库存。按产品（卡口分左右）显示当前结存，可按客户、订单、型号等筛选。

这一页只能看不能改：成品结存是出入库单据算出来的，改数一律走入库单/出库单/红字冲销。这一点和「部件台账」不同——部件台账可以手工调整。

导出到 Excel

工具栏的「导出到Excel」导的是当前筛选结果（不是当前这一页，也不是全部数据）， 末尾带一行合计。想导全部就先把筛选条件清空。导出前会先数一下有多少条再让你确认； 单次最多 5000 行，超了会提示缩小范围——不会悄悄少导几行。 一条都没有时会直接告诉你「没有可导出的记录」，不会再多问一遍要不要导。

批量导入（上线搬账用）

系统刚上线时，手工账上已经有一批成品库存要搬进来。一条条录太慢，可以用工具栏的「批量导入」。

导入不是「直接改库存数」。它会生成一张期初单并立即生效，库存是被这张单据顶上去的—— 跟你手工录入库单是同一个道理。这张单在「成品出入库」里查得到，录错了可以红字冲销。 本系统的库存永远只由单据驱动，没有任何一个入口能绕过单据改数。

操作步骤：

  • 点「批量导入」→ 下载导入模板。模板里已经把可以录期初的产品行全部填好了 （订单号、客户、型号、规格、边别、订单数都带出来），你只需要在「期初数量」列填数， 没有库存的行留空或整行删掉就行。
  • 前两列（产品行ID、订单号）不要改。系统靠它们认这批货挂在哪张订单的哪个产品上， 导入时还会把两者对一遍，对不上直接报错——这样即使排序时不小心只排了一列，也不会静默导到别的订单上。
  • 含卡口的产品在模板里已经拆成左、右两行，分别填数量即可，边别列不用自己动。
  • 模板附了一页「填写说明」，每列怎么填都写在里面。
只有打开了「期初补录」开关的订单才会出现在模板里。 期初是不走装配闸门的（上线前的存量本来就没在系统里装配过）， 要是允许挂到正常订单上，就等于绕过「已装配 − 已入库」凭空加库存。
正常订单的成品请走「成品出入库 → 成品入库」，先完成装配再入库； 如果这确实是上线前的历史订单，先到「订单管理」把它的「期初补录」开关打开，再重新下载模板。
  • 有一行不合格，整批都不会入库。系统会告诉你哪一行、错在哪、一共几条有问题， 数据整批回滚。按提示改完整个文件重新上传即可，不用担心前面的行被导过了。
  • 同一份文件不要导入两次：每次导入都会生成一张新的期初单，库存会被加第二遍。真导重了就把多出来的那张单红字冲销掉。

4.5 呆滞品管理

菜单位置：物料管理 → 呆滞品管理。

订单做完发完了，仓库里还剩下一些成品没处理掉——多做的、退回来的、客户不要了的，这些就是呆滞品。 它们已经不属于任何一张在跑的订单了，所以不能挂在订单上记，单独在这一页建档。

这一页是一本独立的账：不进订单跟踪台账的四个数，也不进「成品库存」。 它跟订单的世界是分开的，别拿这里的数去对台账。

一条记录 = 一批货

同一个货号、同一个客户，先后可能剩下好几批呆滞品（这次剩 200 支、下个月又剩 50 支）， 各建各的记录，系统不会把它们合并。这样每一批是什么时候、哪张生产单留下来的，事后都查得到。

建档要填：货号、客户、生产单号（这批货是哪来的）、产品类型/节数/规格/表面处理/颜色/边别（这批货是什么），以及单位和期初数。

  • 「客户」和「生产单号」至少要填一个。呆滞品已经脱离了订单，这两项是日后认领这批货的 仅有线索——两个都空着，过一阵子就没人说得清这是谁的货、从哪张单剩下来的了。 两个都填当然更好；只知道其中一个也没关系，填上那个就能保存。
  • 单位可选「套」或「支」，按仓库盘点时怎么报就怎么填。这一行的四个数量都按这个单位算，页面顶上的合计会统一折成支（1 套 = 2 支）。
  • 建档后就不能改单位了（只要登记过出入库）——改了的话历史那几笔记的数含义就全变了。真要换，先把流水删掉，或者另建一条。
  • 表面处理选「电泳」会自动带出「黑色」，选「喷涂」自动带出「白色」，这两个是厂里最常见的搭配。自己改过颜色之后就不会再被自动改掉了。

四个数怎么来的

列怎么来的
期初数建档时填的，就是这批呆滞品一开始有多少。填错了可以编辑改。
入库数不能直接填：是所有「入库」流水的合计（退货回来了、盘点多出来了）。
出库数不能直接填：是所有「出库」流水的合计（清库处理掉了、降价卖了、内部领用了）。
结存数期初数 + 入库数 − 出库数，系统自动算，现在还剩多少。

后面进了货或者出了货，点这一行的「出入库」登记一笔：选入库还是出库、填日期、数量、原因。 每登记一笔就留一条流水，点行首箭头展开能看到这条呆滞品的全部进出记录，以及每一笔之后还剩多少。

结存不能为负。出库数量超过当前结存会被直接拒绝——账上只有 6 套，发不出 10 套。

登记错了怎么办

展开行里每一笔流水后面都有「删除」，删掉之后累计数和结存会跟着回滚。 这跟「部件台账」不一样——部件台账只能反向再调一笔，呆滞品这本账允许直接删。

有一种情况会拦你：删一笔入库会让结存变少，如果这批货后来已经出掉了，删完就成负数了，系统会拒绝。 这说明你要删的其实是那笔出库记录，先删它。

整条呆滞品记录只有在一笔流水都没有的时候才能删除，否则要先把流水删干净——不然已经发生的进出就凭空消失了。

批量导入 / 导出

货多的时候不用一条条建档，点工具栏的「批量导入」，先下载导入模板， 照着填好再传上来。模板里附了一页「填写说明」，每一列该怎么填都写在里面。

导入的每一行都会新建一条记录，不会合并、不会覆盖——因为同一个货号同一个客户， 先后剩下的几批本来就要分开建档。所以同一份文件不要导入两次，会重复建档。
  • 「客户」和「生产单号」至少要填一个，规则跟手工建档一样。
  • 入库数、出库数不能导入：它们是出入库流水的累计值，只能在页面上逐笔「登记出入库」，这样每一笔进出才有据可查。导入只能填期初数。
  • 有一行不合格，整批都不会入库。系统会告诉你哪一行、错在哪、一共几条有问题， 数据整批回滚，库里不会留下半批。按提示改完整个文件重新上传即可，不用担心前面的行被导过了。

「导出」导的是当前筛选结果（不是全部数据），导出前会先数一下有多少条再让你确认。 想导全部就先把筛选条件清空。单次最多 5000 行，超了会提示你缩小范围——不会悄悄少导几行。 一条都没有时会直接告诉你「没有可导出的记录」，不会再多问一遍要不要导。

第5章 订单跟踪台账（核心）

菜单位置：订单跟踪台账（一级菜单，在最上面）

这是整个系统的核心产出，对应车间原来手工维护的那张 Excel 跟踪表。一行 = 一个订单产品；部件组的明细（图号、料厚、各部件外发回厂了多少）在展开行里看。

表头分成「部件」和「成品」两栏，两栏的「支」不是一回事：
  • 部件栏（外发已回货 / 外发欠数）按零件数——一套三节轨含外轨、中轨、内轨三个零件， 20 支的订单要送去表面处理的是 20×3 = 60 支零件。
  • 成品栏（订单数 / 入库 / 出货 / 库存 …）按整轨数——装出来、入库、发货的都是整套滑轨。
所以看到「外发欠数」比「订单数」还大，是正常的，不是算错了。

5.1 四个数怎么读

列怎么来的
订单数该产品的订购支数
成品入库累计已确认的入库数（含期初）− 对应红字冲销
成品出货累计已确认的销售出库数 − 对应红字冲销
库存数该产品当前结存
部件组该产品拆了哪几个组（如「外轨/中轨/内轨」），明细在展开行里
外发已回货该产品各部件组回厂数量的合计；逐个部件回了多少，展开行里分组列出
外发欠数 还有多少支零件在加工厂没回来 = 应外发量 − 已回货量。
这里的应外发量是「各部件组支数之和」，不是产品的订单数——零件是分开送去表面处理的， 一个 20 支的三节轨产品拆成外轨/中轨/内轨三组，实际要送出去的是 20×3 = 60 支零件。
表面处理选「无」的产品显示「—」（不走外发，不适用）。想知道是哪个部件还没回来，展开这一行看部件组明细。
装配完成已填「实际完成」的批次合计。分体行（含只出内轨的行）同样要装配自身小零件，一样出数字
订单编号显示的是生产单号
装配车间该产品各装配批次的车间；分在不同车间会并列显示（如「装二/装五」）
所有数字都是实时算出来的，不存冗余字段。所以只要单据对，台账就一定对，不存在「数据没同步」的情况。

5.2 两个欠数的区别

欠数算法回答的问题
成品欠数订单数 − 成品入库生产视角：还差多少没做完
发货欠数订单数 − 成品出货销售视角：还欠客户多少货

举例：订单 1000 支，已入库 1000 支、已出库 600 支 → 成品欠数 0（车间做完了），发货欠数 400（客户还没提完）。

欠数可以是负数：超产就是负的成品欠数，超发就是负的发货欠数，系统照实显示不截断。

这两个欠数都在「成品」栏下，算的是整轨支数。 「部件」栏里还有个外发欠数，那个算的是零件支数，跟这两个不是一个量级，别混着看。

5.3 筛选与展开行

  • 筛选：关键字（订单号/客户/生产单号/型号/货号/生产图号）、业务员、跟单员、表面处理、装配车间、产品类型、交期区间，另有两个常用开关——只看有欠数、只看逾期。
  • 汇总卡：顶部六张卡是当前筛选口径的整体合计，不受分页影响。
  • 展开看明细：点行首箭头展开，从上到下四段——
    • 部件组明细：这个产品拆了哪几个组，每组的组型号、生产图号、版本、料厚、组支数，以及该部件外发回厂了多少支、还欠多少支。外发是按部件走的，这一段就是看「哪个部件还没回齐」的地方——主行的「外发欠数」就是这一列的合计。
    • 成品出入库流水（只列已确认单据）、外发回厂流水（逐笔，带部件组标明是哪个部件回的厂）、装配批次。
    查「这批货到底走到哪一步了」不用来回切菜单。
  • 状态标签：逾期（红）= 交期已过且还欠发货；已交清（绿）= 发货欠数 ≤ 0；跟进中（黄）= 其余。
  • 导出 Excel：筛选栏右侧「导出」按钮，导出的是当前筛选的全量（不是当前这一页），同样一行一个产品，末尾带一行合计。生产图号 / 版本 / 料厚这些组级字段会按组序并列在一格里（如 DWG-OM/DWG-IN）——Excel 是平表塞不下嵌套，而按组铺行会让每行重复一遍产品的进度数、合计直接翻倍。过渡期可以和手工表并排对账。
    单次最多 5000 行；超过会提示先缩小范围（按客户 / 交期区间 / 只看有欠数），不会静默少导——截断出去的表拿去对账比不给更糟。

5.4 订单自动完结与重开

  • 出入库确认或冲销后，系统会自动检查：这张订单所有产品的发货欠数都 ≤ 0 → 订单自动完结。
  • 反过来，已完结的订单如果因为冲销让某个产品的发货欠数又变正了 → 自动重开。
  • 也可以在订单列表手工点「完结」/「重开」。
完结只是「不再跟踪」的台账口径，不锁单据。客户临时追加提货，已完结订单照样可以出库。

第6章 首页看板

登录后的落地页，销售视角的待办汇总。只统计「进行中」的订单——已完结的不再跟踪，不该占用注意力。

四张汇总卡

卡片含义
进行中订单当前还在跟的订单张数
总成品欠数所有进行中订单还差多少支没做完
总发货欠数所有进行中订单还欠客户多少支
逾期订单交期已过且还欠发货的订单张数
看板的欠数只累加欠的部分，某个组超发了不会去抵消另一个组欠的量——B 客户的货没到，不会因为 A 客户多发了就算平。台账的汇总卡是净额口径，两者服务的问题不同，数字对不上是正常的。

两张待办卡

左卡用页签切换两个交期视角，标签上的数字是总条数（不是当前显示的条数）：

  • 逾期未发货：交期已过且还欠货，逾期最久的排最前。
  • 临近交期（7 天）：今天起 7 天内到期且还欠货，剩 2 天内的标红。

打开首页时若没有逾期、却有临近到期的，会自动停在「临近交期」页，省一次点击。

右卡「近期外发回厂」：最近几条回厂记录（回厂日期、加工商、产品型号、表面处理、数量）。系统不记「计划什么时候回」，所以没有超期提醒——要看全部记录，点右上角「查看外发」去外发管理。

每张列表最多显示 10 条，超过会提示「共 N 条，仅显示前 10 条」；没有数据时收成一行横幅（如「暂无逾期，交付良好」），不会撑出一张空表。

列表只露 5 行左右，条数更多时会自动缓慢向下滚动轮播，滚到最后一行停一下再回到开头。鼠标移到列表上即暂停，方便看清某一行；移开后继续滚。也可以直接用滚轮自己翻，翻完移开鼠标会从你停下的位置接着滚。

第7章 上线准备：期初录入

菜单位置：物料管理 → 期初录入

系统刚上线时，车间和仓库已经有一堆在做的订单和现成的库存。期初录入就是把这些「上线之前就存在的数」一次性搬进系统，之后台账才对得上。

这一章是上线阶段的一次性工作，日常业务用不到。做之前先跟管理员确认好口径。

7.1 先补录未完结的历史订单

  1. 把还没交完的历史订单，按第 1 章的方式正常录进系统。
  2. 录的时候把订单信息里的「期初补录」开关打开——这样会免掉订单来源、附件之类非关键项的必填校验，四个数的口径与正常订单完全一样。
  3. 录完之后再来挂期初库存。

7.2 成品期初

「成品期初（挂订单）」页签，用于还没交完的订单已经做好入库的那部分。 点「添加产品」选具体的订单产品录数量（与成品入库同一个选择器）， 这部分会计入该订单的完成数与欠数。

  • 期初单据走成品出入库通道，单号是 FGO 开头，保存即生效（不需要再点确认）。
  • 期初不受装配闸门约束——上线前的存货本来就没在系统里走过装配。
  • 录错了同样可以红字冲销。
「添加产品」里只会列出打开了「期初补录」开关的订单。 找不到你要的订单？回「订单管理」编辑那张单，把期初补录开关打开再来。
为什么要这么卡：期初不过装配闸门，如果允许挂到正常订单上，就等于跳过装配 凭空给那张订单加上完成数和库存。正常订单的成品请走「成品出入库 → 成品入库」。
订单早就完结、仓库只是还剩一些货的，不在这里录——那是呆滞品， 请到「物料管理 → 呆滞品管理」逐批建档，见 4.5。

7.3 部件期初

还没装配成成品的半成品部件（外轨/中轨/内轨），录在「部件期初」页签。

部件不挂订单，按七个属性归集：部件类型、边别、货号、节数、产品类型、料厚、规格。属性完全一致的会累加到同一条余量记录上。

部件期初是整批全有全无：一批里只要有一行填错，整批都不入库，改完重新提交。这样设计是因为部件台账是累加的——如果部分成功，你改完错行再交一次，正确的那些行就会被重复累加。

7.4 部件台账

菜单位置：物料管理 → 部件台账。查半成品部件的当前余量。

  • 余量的唯一修改方式是「调整」：填增减数量 + 选原因，系统留一条流水。没有「直接把余量改成 X」这种操作。
  • 调整原因是下拉选择：期初补录 / 盘盈盘亏 / 录错纠正 / 其他。选「其他」要再填一句具体原因，流水上会记成「其他：xxx」——只记一个光秃秃的「其他」等于没写，事后查不出所以然。
  • 点余量行可以下钻看它的全部变动流水（期初 / 手工调整，各条都有人和原因）。
当前版本部件台账是一本「参考账」：只有期初和手工调整，不会跟着外发、入库自动加减。因为系统不做车间报工，部件的产出没有采集点。需要用它对账时，请配合人工盘点。

批量导入 / 导出

盘点完一大批部件时不用一行行调，点「批量导入」，先下载导入模板照着填。 模板附了一页「填写说明」，每列怎么填都写在里面。

导入的是「调整量」，不是「余量」。 模板里那一列填的是要增减多少（正数加、负数减），系统会在现有余量上加减，并给每一行留一条流水。 这跟页面上的「调整余量」是同一回事，只是一次做很多行。
所以同一份文件不要导入两次——会再加一遍。
  • 货号、部件、边别、节数、产品类型、料厚、规格这 7 项共同决定是哪一行台账，任一项不同就是另一行。填之前建议先导出一份看看现有的行是怎么写的。
  • 调整量不能填 0（没有意义的空流水），调整原因必填，会记进流水。
  • 有一行不合格，整批都不会入库。系统会告诉你哪一行、错在哪、一共几条有问题， 数据整批回滚。某一行会把余量扣成负数也算不合格，同样整批退回—— 不会出现「前几行加了、后面失败」这种半截账。

「导出」导的是当前筛选结果，导出前会先数一下有多少条再让你确认。想导全部就先清空筛选条件。 单次最多 5000 行，超了会提示缩小范围——不会悄悄少导几行。 一条都没有时会直接告诉你「没有可导出的记录」，不会再多问一遍要不要导。

基础数据改了不会影响已有单据：单据在创建时就把关键字段抄了一份快照。比如客户改名，历史订单上显示的还是当时的名字——这是有意的，否则历史单据会失真。

批量导入的通用规则：先下载模板 → 按模板填 → 上传。整批校验全部通过才入库，任何一行有问题都会列出行号和原因，一行都不会入。

HR · 人事档案

菜单位置：HR人力资源管理 → 人事档案。 用来建厂内员工花名册（工号、用工属性、车间岗位等）。

独立模块、单向依赖：录入时可选用「基础数据 → 部门信息」作为所属组织； 暂不向订单、外发、装配等业务模块供数（业务员/跟单员等仍按原方式手填或选客户默认值）。日后打通另说。

员工编号是系统自动生成的

不用手工填工号，也填不了。保存时系统按公司《员工编码管理规则》自动生成一个 10 位纯数字的编号，全公司唯一：

位置是什么取自哪里
第 1-2 位厂区表单里选的厂区：01 总厂 / 02 一号分厂 / 03 二号分厂
第 3-4 位年份标识 2026年1月1日（含）之后入职的填入职年份后两位（2026→26）；
之前入职的老员工统一填 99
第 5-7 位部门编码所选部门的人事编码（如品检部 005），在「基础数据 → 部门信息」里维护
第 8-10 位流水号同厂区、同年份、同部门内按建档先后 001 起排；每年 1 月 1 日自动从 001 重来

例：0199005036 = 总厂 + 2026 年前入职 + 品检部 + 该部门存量第 36 人；
0126009018 = 总厂 + 2026 年入职 + 模具部 + 本年度该部门第 18 位；
0126010007 = 总厂 + 2026 年入职 + IT部 + 本年度该部门第 7 位；
0126011012 = 总厂 + 2026 年入职 + 计划部 + 本年度该部门第 12 位。

99 只是「老员工」的标记，不代表哪一年入职。真实入职时间、工龄、年假一律看 入职日期字段，不要拿编号去推。

新增时把厂区、入职日期、所属组织填全，编号框就会显示形如 0126005??? 的预览（问号是流水号，保存时才定）。这三项缺一个都存不了，系统会明确告诉你缺哪一项。

选到的部门必须先配好人事编码，否则保存会被拒绝。部门树里会直接标出来， 配好的显示成「品检部（005）」，没配的显示「（未配人事编码）」。 去「基础数据 → 部门信息」编辑那个部门，填 3 位数字即可。

正式员工编号一旦生成，终身不变

  • 调岗、升职、跨厂区调动都不换号。调去别的厂区就改「厂区」字段，编号原样不动——所以老员工的编号前两位可能和他现在的厂区对不上，这是规则要求的，不是出错。
  • 离职后编号永久封存，不会再分给别人。离职返聘按新员工重新建档、生成全新编号。

非正式用工（实习生/临时工/学徒/派遣工）转正时要换号，见下一节。

非正式用工带字母前缀

只有正式工是 10 位纯数字，其余四类都在前面加一个字母区分：

用工属性前缀示例
实习生SS0126001005
临时工LL0199002012
学徒AA0126001023
劳务派遣工PP0126001016
正式工无0126010007

字母后面那 10 位数字的编法和正式工完全一样（同厂区、同年份、同部门共用一套流水号）， 方便人事统一统计。

派遣工的劳动关系在外派公司，我们只登记他在哪个厂区、哪个部门干活； 用工结束后编号作废封存，不会再分给别人。

转正时要换号。把用工属性从实习生/临时工/学徒/派遣工改成正式工， 保存时系统会问你要不要换发正式编号。选「换发新编号」就生成一个不带字母的 10 位正式编号， 原编号注销归档、不再启用；选「保留原编号」则不动。

四类非正式用工之间互相改（比如实习生转学徒）也会问一次，因为字母前缀跟着要变。

字段分四块

  • 基本信息：员工编号（自动生成）、厂区、姓名、性别、身份证、联系方式、籍贯、民族、婚姻状况、政治面貌、住址、紧急联系人。年龄按出生日期自动算，不单独存。
  • 教育背景：学历、学历类型（全日制/非全日制）、专业、最终毕业院校、毕业时间（按年月）。
  • 用工属性：正式工/临时工/派遣工/学徒、入职日期、试用期（月）、合同到期日、在职/离职；离职须填离职日期（可填原因）。离职时档案会自动停用。
  • 车间属性：所属组织（部门树）、岗位、班组（手填）、直属车间主管（选本表在职员工）。

录入是一个独立页面

点「新增员工」或「编辑」会跳到一个单独的录入页（不是弹窗）——档案字段分四大段， 弹窗里塞不下。填完点右上角保存即返回列表；点返回列表或取消则放弃本次录入。

岗位下拉会按部门过滤

岗位来自「基础数据 → 岗位管理」。选好所属组织后，岗位下拉只列 该部门的岗位 + 通用岗位（通用岗位后面标着「（通用）」，如文员、司机这类跨部门岗位）。

  • 部门里岗位没配全、一时选不到想要的？勾上岗位下方的「显示全部岗位」就不再过滤。
  • 换了部门后，原来选的岗位如果不属于新部门，系统会自动清空并提示，请重新选一个。
  • 这只是录入引导，系统不强制岗位必须属于该部门——借调、一人多岗都是现实存在的。
  1. 打开「人事档案」，点「新增员工」进入录入页。
  2. 先填基本信息与教育背景（厂区必选），再填用工属性与入职日期；最后选所属组织与岗位，需要时可指定直属主管。
  3. 保存。编号自动生成，提示条会告诉你生成的是哪个号。列表可按关键字、组织、厂区、用工属性、岗位、在职状态筛选。
用工属性、婚姻状况、政治面貌、学历等选项在系统管理 → 数据字典维护 （类型 emp_type / marital_status / political_status / education）。 学历类型为系统固定项（全日制 / 非全日制）。
岗位和职级都不在数据字典里，它们是独立主数据，分别在 「基础数据 → 岗位管理」和「基础数据 → 职级管理」维护。

第9章 管理员篇

给新员工开账号

  1. 系统管理 → 用户管理 → 新增，填账号、姓名、部门、手机号。
  2. 勾选角色。系统内置 17 个岗位角色（总经理、业务员、跟单员、计划员、仓管员…）。
  3. 保存后把初始密码给本人，首次登录会强制改密。

角色与权限

  • 系统管理 → 角色管理 → 分配权限，勾选该角色能看的菜单和能点的按钮。
  • 菜单 = 看这个页面的权限，按钮 = 在这个页面上操作的权限。权限树里每个节点都标了「查看」或「操作」。
  • 父子勾选互不联动：勾了「订单管理」不会自动勾上它下面的新增/编辑/删除。要给谁配只读，就只勾菜单、不勾按钮。
  • 弹窗顶部有三个快捷键：全选 / 仅授只读（一键勾上全部「查看」类权限）/ 全部清空。
  • 只勾了某个按钮忘了勾菜单也没关系，保存时系统会自动把该页面的查看权限补上，不会出现「菜单点得进去、列表却报没权限」。但同级的其它菜单不会被连带授权，需要哪个页面就勾哪个。
  • 首页看板的经营数字（进行中订单、双欠数、逾期）由「统计查看 → 查看首页看板」控制。取消勾选后该用户的首页只剩欢迎区与日历，不会报错。
  • 改完权限，相关用户必须重新登录才生效（权限写在登录令牌里）。
  • 内置角色不能删除，但可以改权限、可以临时停用。
  • admin 恒定拥有全部权限，不需要也不应该手工配。

谁改的这条记录

订单、外发回厂记录、装配批次、出入库单、客户、部件、字典、账号、角色等记录都会留下创建人 / 创建时间 / 最后更新人 / 更新时间。

  • 列表页：单号（或代码、名称）后面有个 ⓘ 小图标，鼠标悬停即可看到四项信息，不用点进去。
  • 详情/编辑页：页面底部有一条独立的审计信息栏。
  • 姓名记的是操作当时的姓名，即使该账号后来被停用或删除，历史记录依然查得到是谁做的。

数据字典

系统管理 → 数据字典。表面处理、装配车间、产品类型这些下拉选项都在这里维护，业务上新增一种表面处理不需要改代码。

表面处理里的「无」是保留值，不能删也不能改它的键值——系统靠它判断产品需不需要外发。

业务字段开关

第10章 常见问题 FAQ

订单

Q：订单为什么不能编辑/删除？
A：它已经被外发回厂记录、装配批次或出入库单引用了。提示里会说明被几条什么单据引用。要改先把下游记录删掉或冲销掉。

Q：生产单号填在哪？我在产品行里找不到了。
A：生产单号是订单级字段，在订单信息区、PO# 旁边。一张订单只有一个生产单号。

Q：客户图号和生产图号有什么区别？
A：客户图号是客户来图上的编号，填在产品行；生产图号是我们内部转化的技术图纸编号，填在部件组，而且填了会自动带出开单信息。

Q：订单里怎么没有装配车间了？
A：已经取消了。车间在录装配批次的时候选，那时候才知道排给谁做。

外发

Q：为什么外发还是按部件组选，装配和入库却按产品选？
A：外发是把零件分开送去电镀、分批回厂的，得知道是哪个部件回来了；装配装出来的是整套滑轨，入库发货也是整套，没有拆开的概念。所以两边粒度不同，这是设计如此。

Q：加工商的送货单上只有数量、没有重量，能登记吗？
A：能，这是默认方式。录入方式保持「按数量」，直接填回厂数量就能保存，重量和单重留空即可，不影响入库和台账。

Q：我填好了数量，又补填了重量，数量怎么变了？
A：那是「按重量折算」方式，重量会驱动数量。要以送货单数量为准，就把录入方式切回「按数量」——这时填重量不会再改动数量。

Q：保存时提示「数量与重量折算不一致」。
A：三个数都填了，但数量和「重量÷单重」相差超过 10%，多半有一处录错了（常见是单重不对）。核对后点「按登记数量入账」即可，系统以你填的数量为准。

Q：保存提示「请按送货单填写回厂数量」。
A：那一行数量还是 0。按数量方式直接填数量；按重量折算方式则填重量与单重，数量会自动算出（单重没有的话去「基础数据 → 部件信息」补，或直接在行里手工填）。

Q：外发件发出去了，系统里怎么没有记录？
A：系统只记回厂——发出去的时候不用建单，货回厂了再登记一条。发出去的加工单照原来那样手写。

装配与入库

Q：入库确认时提示超过可入库量。
A：可入库量 = 已完成装配量 − 已入库量。多半是装配批次录了但没填「实际完成」日期，系统就不认为它装完了。

Q：装配批次删不掉。
A：删了会让可入库量变成负数，说明这批已经被入库消耗了。要先把对应的入库单红字冲销。

Q：期初入库为什么不用管装配？
A：上线之前的存货本来就没在系统里走过装配流程，硬卡会让这个产品永远入不了库。

Q：卡口产品左边装了 4 支，右边只能入 3 支？
A：对，左右额度分开算、不能串。右边要多入就先在装配管理把右边的批次补上。

台账与看板

Q：台账的合计和首页看板的数字对不上。
A：正常。看板只算「进行中」订单且只累加欠的部分；台账算的是当前筛选范围的净额（含超产超发抵扣）。两者回答的是不同问题。

Q：订单明明还没发完，怎么自动完结了？
A：完结看的是发货欠数。如果所有产品都已出库达到订单数就会完结。要继续跟踪点「重开」即可，完结也不影响继续出入库。

Q：台账某行的装配车间是空的。
A：这个产品还没录任何装配批次。车间来自批次，没批次自然没车间。

Q：订单 20 支，外发欠数怎么显示 28？比订单数还大。
A：没错。外发欠的是零件不是成品——20 支三节轨要送出去外轨、中轨、内轨三个部件， 共 60 支零件；已经回来 32 支，就还欠 28 支。展开这一行能看到是哪个部件还没回。

Q：外发欠数显示「—」。
A：这个产品的表面处理是「无」，根本不需要外发，所以这一栏不适用。

Q：以前台账一个产品占三行（外轨/中轨/内轨），现在只有一行了？
A：改过了。四个数（订单数/完成数/库存数/双欠数）现在都在产品这一层，一个产品就一行；生产图号、料厚、各部件的外发回厂进度点开展开行看。以前按组铺行，同一个产品的订单数会重复三遍，看起来像是订了三倍的量。

其它

Q：菜单少了几项 / 按钮点了提示没权限。
A：角色权限问题，找管理员加。加完要重新登录。

Q：页面按钮点了没反应。
A：多半是系统刚更新过、你的页面还是旧版本。刷新一次（Ctrl+F5）即可。

Q：「颜色」或「客户图号」这一栏突然不见了，以前录的是不是没了？
