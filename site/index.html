海宝五金订单跟踪系统

接单 → 外发 → 回货 → 入库 → 出库 · 订单数 / 完成数 / 库存数 / 欠数 一目了然

查看设计文档（评审版）

订单数

客户订购数量，统一折算为「支」；套/支自动换算，1 套 = 2 支。

完成数

累计成品入库数量，生产欠数 = 订单数 − 完成数。

库存数

当前成品结存，按订单产品行（卡口分左右）实时聚合。

欠数

双口径并列：生产欠数（还差多少没做完）与发货欠数（还欠客户多少货）。

业务主线

客户下单→ 创建订单→ 部件外发（可选）→ 外发回货（可选）→ 成品入库→ 成品出库
